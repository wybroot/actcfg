# 项目说明

本目录根据 `需求描述.docx` 中的业务要求，整理形成企业私有化交付编排与自动部署平台的方案文档。平台定位为“交付编排中心”，不替代 Harbor、Nexus、CMDB、监控平台等已有系统，而是对交付资源、客户环境、部署方案、部署包和现场 Agent 执行进行统一编排。

## 文档清单

| 文件 | 说明 |
| --- | --- |
| 01-总体产品方案.md | 平台定位、MVP 边界、角色、核心模块和产品价值 |
| 02-技术方案.md | 系统架构、技术选型、后端服务、Agent、安全和扩展设计 |
| 03-数据库设计方案.md | 核心数据表、关键字段、关系和索引建议 |
| 04-接口方案.md | REST API 设计、认证、产品仓库、部署配置、Agent 和日志接口 |
| 05-业务流程方案.md | 产品入库、部署配置、客户环境、部署包、Agent 和权限流程 |
| 06-使用方案.md | 超级管理员、运维管理员、实施工程师的使用流程 |
| 07-开发计划.md | 分阶段建设计划、优先级和验收标准 |
| 08-部署方案.md | 平台部署架构、环境要求、部署步骤、备份和安全加固 |
| 09-原型设计方案.md | 菜单结构、主要页面字段、操作和表单校验建议 |

## 需求覆盖情况

- 产品仓库：已调整为交付资源索引和编排入口，避免重复建设 Harbor/Nexus 能力。
- 部署配置：已覆盖方案、组件、模板、环境变量、克隆复制、版本化和发布后只读。
- 客户管理：已覆盖客户基础信息、联系人、运维信息。
- 客户环境配置：已覆盖环境隔离、服务器、中间件、数据库、方案版本绑定和环境变量。
- 部署包：已覆盖不可变部署包、manifest.json、checksum.sha256、目录结构、下载和审计。
- Agent 管理：已明确 MVP 优先离线部署，覆盖环境检测、幂等执行、失败续跑、健康检查、日志和报告。
- 日志记录：已覆盖操作日志、下载日志、Agent 执行日志、登录日志和敏感信息脱敏。
- 用户权限：已覆盖基础 RBAC；复杂组织、岗位和数据权限作为后续增强。
