# 部署方案

## 1. 部署目标

企业私有化交付编排与自动部署平台部署在公司内网或云上环境，供运维管理员、实施工程师、超级管理员使用。平台定位为交付编排中心，优先支持离线部署包生成和 Agent 现场自动化执行，不替代 Harbor、Nexus、CMDB、监控等已有系统。

## 2. 部署架构

```text
用户浏览器
  -> Nginx / 网关
  -> 前端静态资源
  -> 后端 API 服务
  -> MySQL
  -> Redis
  -> MinIO / 文件存储
  -> Harbor / 内部仓库

客户现场服务器
  -> Agent
  -> 离线部署包
  -> manifest.json / checksum.sha256
  -> 本地部署日志和部署报告
```

## 3. 环境要求

### 3.1 平台服务器

| 项目 | 建议配置 |
| --- | --- |
| 操作系统 | Linux x86_64 |
| CPU | 4 核及以上 |
| 内存 | 8 GB 及以上 |
| 磁盘 | 200 GB 起，根据制品和部署包容量扩展 |
| 网络 | 可访问公司内部 Harbor、制品库、对象存储；客户现场可不访问平台 |

### 3.2 基础软件

| 软件 | 建议版本 | 用途 |
| --- | --- | --- |
| JDK | 17 | 运行后端服务 |
| MySQL | 8.x | 业务数据库 |
| Redis | 6.x/7.x | 缓存和任务状态 |
| Nginx | 1.22+ | 静态资源和反向代理 |
| MinIO | RELEASE 版本 | 对象存储 |
| Docker | 24+ | 可选，用于容器化部署 |

## 4. 容器化部署建议

建议通过 Docker Compose 或 Kubernetes 部署平台组件。

### 4.1 服务清单

- delivery-web：前端静态资源服务；
- delivery-api：后端 API 服务；
- mysql：业务数据库；
- redis：缓存；
- minio：文件存储；
- nginx：统一入口；
- worker：部署包生成任务服务，可与 API 合并或独立部署。

### 4.2 配置项

| 配置项 | 说明 |
| --- | --- |
| DB_HOST | MySQL 地址 |
| DB_PORT | MySQL 端口 |
| DB_NAME | 数据库名称 |
| DB_USERNAME | 数据库用户 |
| DB_PASSWORD | 数据库密码 |
| REDIS_HOST | Redis 地址 |
| STORAGE_TYPE | 文件存储类型：LOCAL、MINIO |
| MINIO_ENDPOINT | MinIO 地址 |
| HARBOR_ENDPOINT | Harbor 地址 |
| JWT_SECRET | Token 签名密钥 |
| AGENT_REGISTER_SECRET | Agent 注册密钥 |

## 5. 平台部署步骤

```text
准备服务器
  -> 安装基础软件
  -> 初始化 MySQL 数据库
  -> 配置文件存储
  -> 部署后端服务
  -> 部署前端静态资源
  -> 配置 Nginx 反向代理
  -> 初始化超级管理员
  -> 验证系统功能
```

## 6. Agent 部署步骤

### 6.1 离线模式

```text
下载安装包
  -> 上传到客户现场服务器
  -> 解压 Agent
  -> 配置工作目录
  -> 导入部署包
  -> 校验 manifest.json 和 checksum.sha256
  -> 执行环境检测
  -> 执行部署
  -> 失败时从失败步骤续跑
  -> 查看部署报告
```

### 6.2 在线模式

在线模式属于后续增强能力，MVP 阶段不作为强依赖。

```text
生成 Agent 注册码
  -> 客户现场安装 Agent
  -> 执行注册命令
  -> Agent 与平台建立连接
  -> 平台下发任务
  -> Agent 执行并上报日志
```

## 7. 备份与恢复

### 7.1 备份对象

- MySQL 数据库；
- 文件存储目录或 MinIO bucket；
- 平台配置文件；
- Agent 任务日志。

### 7.2 备份策略

- MySQL 每日全量备份，关键业务期增加增量备份。
- 文件存储按目录或 bucket 定期快照。
- 部署包可根据生命周期策略清理，但需要保留元数据和审计日志。

## 8. 运维监控

建议监控以下指标：

- API 服务存活状态；
- MySQL 连接数、慢 SQL、磁盘占用；
- Redis 内存和连接数；
- 文件存储容量；
- 部署包生成任务成功率；
- Agent 在线数量；
- Agent 任务失败率；
- 下载接口访问量。

## 9. 安全加固

- 平台入口使用 HTTPS。
- 管理端限制内网访问或 VPN 访问。
- 数据库、Redis、MinIO 不直接暴露公网。
- 敏感配置通过环境变量、配置中心或加密字段注入。
- 部署包内敏感配置应加密、占位或部署时输入。
- Agent 日志和部署报告必须对密码、Token、密钥等内容脱敏。
- 定期轮换 Agent 注册密钥和 JWT 密钥。
- 文件下载接口必须鉴权并记录日志。
- 部署包生成成功后不可变，重新交付必须生成新包。
