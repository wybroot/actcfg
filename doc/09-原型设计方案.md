# 原型设计方案

```text
  |   |-- 产品资源
  |   |-- 资源版本
  |   |-- 文件管理
  |   |-- Harbor 同步
  |-- 部署配置
  |   |-- 部署方案
  |   |-- 方案版本
  |   |-- 组件编排
  |   |-- 配置模板
  |-- 客户管理
  |   |-- 客户信息
  |   |-- 联系人
  |   |-- 运维信息
  |-- 客户环境
  |   |-- 环境列表
  |   |-- 服务器清单
  |   |-- 环境变量
  |   |-- 方案绑定
  |-- 部署包管理
  |   |-- 部署包列表
  |   |-- 生成记录
  |   |-- 下载记录
  |-- Agent 离线部署
  |   |-- Agent 安装包
  |   |-- 执行报告
  |   |-- 失败续跑记录

      |-- 用户管理
      |-- 角色管理
      |-- 权限管理
      |-- 公司管理
      |-- 部门管理
      |-- 岗位管理
```

## 2. 首页工作台

### 2.1 指标卡片

- 产品资源数量；
- 客户数量；
- 客户环境数量；
- 部署包数量；
- Agent 在线数量；
- 最近部署成功率。

### 2.2 快捷入口

- 上传资源；
- 新建部署方案；
- 新建客户；
- 生成部署包；
- 查看 Agent 任务。

### 2.3 最近动态

- 最近上传资源；
- 最近生成部署包；
- 最近 Agent 执行任务；
- 最近失败任务。

## 4. 部署配置页面

### 4.1 部署方案列表

字段：方案名称、方案编码、当前版本、组件数量、状态、创建人、更新时间。

操作：新建、编辑、克隆、创建版本、查看组件、发布、停用。

### 4.2 组件编排页面

建议采用表格加抽屉或步骤编排视图：

- 组件名称；
- 组件类型；
- 资源版本；
- 部署顺序；
- 配置模板；
- 健康检查；
- 操作。

## 8. Agent 离线部署页面

### 8.1 Agent 安装包

字段：Agent 版本、适用系统、文件大小、checksum、发布时间、操作。

操作：上传安装包、下载、查看校验值、停用。

### 8.2 执行报告列表

字段：报告编号、客户、环境、部署包编号、执行主机、执行状态、开始时间、结束时间、失败步骤、操作。

操作：查看报告、下载报告、查看日志。

### 8.3 失败续跑记录

字段：任务编号、部署包编号、失败步骤、失败原因、续跑次数、最近续跑时间、最终状态。

## 9. Agent 在线管理页面（后续）

### 9.1 Agent 实例列表

字段：Agent 编码、客户、环境、主机 IP、主机名、Agent 版本、在线状态、最近心跳、操作。

操作：查看详情、下发任务、禁用、查看日志。

### 9.2 Agent 任务列表

字段：任务编号、Agent、客户、环境、任务类型、任务状态、开始时间、结束时间、结果摘要、操作。

操作：查看日志、取消任务、下载报告。

## 11. 表单校验建议

- 必填项前端即时校验，后端再次校验。
- 资源版本号、客户编码、方案编码需要唯一。
- 文件上传限制大小和类型。
- 删除被引用资源时应提示不可删除。
- 生成部署包前检查客户环境、部署方案、资源文件是否完整。
- 已发布部署方案版本不允许直接编辑。
- 部署包生成成功后不允许修改，只允许作废或重新生成新版本。
- manifest 和 checksum 生成失败时部署包状态必须为失败。
- 敏感配置字段默认脱敏展示。
